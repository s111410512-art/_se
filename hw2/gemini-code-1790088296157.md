# 模擬金門大學校務行政資訊系統 (Mock NQU Academic System)

這是一個基於 Python Flask 與 Bootstrap 5 開發的輕量級校務系統原型專案。本專案模擬了大學校務系統的核心功能，包含登入驗證、選課作業、成績查詢以及課表視覺化，適合用來作為 Web 開發學習或軟體工程專案的基礎框架。

## ✨ 核心功能 (Features)

*   **🔐 登入與驗證**：提供模擬的學號密碼登入機制，並具備基礎防護驗證碼。
*   **📢 首頁公告**：登入後可查看校園、教務處相關最新公告。
*   **📚 選課系統**：提供即時加選與退選功能，分為「可加選課程」與「已選課程」區塊。
*   **📊 成績查詢**：顯示歷年學期成績單，並自動計算該學期的平均分數。
*   **📅 個人課表**：根據學生選課結果，自動生成星期一至星期五的網格狀視覺化課表。

## 🛠️ 技術堆疊 (Tech Stack)

*   **後端**：Python 3, Flask (輕量級 Web 框架)
*   **前端**：HTML5, Bootstrap 5 (CSS 框架), Jinja2 (樣板引擎)
*   **資料庫**：目前使用 Python 內建的模擬資料結構 (Dict/List)，便於快速啟動與測試。
